# Toolbox — General Tools Website

A clean, light, minimal tools website. Plain **HTML + CSS + JS** — no build step, no dependencies, no sign-up. Open `index.html` and it works.

> Built by **Harmno** — github.com/harmno (watermark on every page and a `Toolbox by Harmno` comment in every code file).

**Converters** — Unit Converter  
**Calculators** — Percentage · Age · BMI

## Mobile

Layout is tuned for phones: single-column cards, horizontally scrollable category chips, stacked actions, compact hero and panels (see `@media (max-width: 560px)` in `css/style.css`).

## The 10-second tool-adding workflow

**Aapko sirf apna code paste karna hai — baaki sab automatic.**

1. **Ek folder banayein** (ya `tools\_template\` copy karein) aur apna code usme daal dein:
   ```
   tools/pdf/merge-pdf/index.html      ← standard: one folder per tool
   tools/pdf/merge-pdf/style.css       ← uske saath ke assets usi folder me
   tools/pdf/merge-pdf/app.js
   ```
   Categories: `pdf` · `image` · `text` · `developer` · `converters` · `calculators`  
   (Single-file tool `tools/pdf/merge-pdf.html` bhi kaam karega.)

2. **`sync-tools.bat` par double-click karein**

3. Website refresh karein — **tool LIVE hai.** Card automatically ban jayega (name `<title>` se, description `<meta name="description">` se, category folder se, icon default/overridable).

Bas itna hi. Koi data file manually edit nahi karni.

### Tool ki details kaise padhi jati hain

| Card pe kya dikhna hai | Kaha se aata hai |
|---|---|
| Name | file ka `<title>` ("— Toolbox" jaisa suffix automatically hata diya jata hai) |
| Description | `<meta name="description" content="...">` |
| Category | folder ka naam (`tools/pdf/...` → PDF category) |
| Icon | optional: file me `<!-- toolbox-icon: braces -->` likhein; warna category ka default |
| Extra icons chahiye? | `ICONS` map in `js/main.js` me apna SVG path add karein |

Tool **hataane** ke liye: uska folder (ya file) delete karke `sync-tools.bat` dobara double-click karein.

### Tips

- Paste karte waqt file **UTF-8** me honi chahiye (most tools are — agar card pe description weird dikhe to file ko "Save as UTF-8" karein).
- Remote/absolute paths (`/assets/...`) se bachein — relative paths (`./assets/...`) use karein, taki folder kahi bhi move ho sake.
- "Coming soon" placeholder cards haath se edit karne hain to `js/tools-data.js` me neeche wale section me hain — sync unhe chhedta nahi.
- Bahari website ka link card banana hai to hand section me `status: 'live'` aur `url: 'https://...'` ke saath entry add karein.

## Toolbox Vault — hidden tools (password: HARMAN)

Logo pe **double-click** karein (kahin bhi, kisi bhi page pe) → **Toolbox Vault** khulta hai.

- Password: **HARMAN** (case-insensitive bhi chalega)
- Secret tools ka folder: `secret/tools/<name>/index.html` — same folder-per-tool pattern
  1. `secret/tools/_template` ko copy karke rename karein (e.g. `my-secret-tool`)
  2. `index.html` me apna kaam build karein
  3. **`sync-tools.bat`** → tool Vault me auto-register ho jayega
- Vault ka URL: `secret/index.html` (site pe kahin link nahi hai, `noindex` hai)
- 5 galat tries ke baad 30-second lockout
- Secret tool pages khud bhi guard karte hain — bina unlock ke direct URL se bhi lock screen pe bounce hote hain

**Honest caveat:** static site pe ye client-side password hai — casual visitors se bachata hai, determined/technical logon se nahi. Koi sach me confidential cheez public hosting pe mat daalo.

## Structure

```
tools website/
├── index.html             Homepage (hero, search, filter, tool grid)
├── css/style.css          Design tokens + all styles
├── js/
│   ├── tools-data.js      Tool registry (auto section + hand-written "soon" cards)
│   ├── main.js            Card rendering, search & filter, icon set
│   └── vault.js           Double-click logo → secret/index.html
├── secret/
│   ├── index.html         VAULT — lock screen (password HARMAN) + hidden tool grid
│   ├── vault-data.js      AUTO-GENERATED by sync-tools.ps1 (do not edit)
│   └── tools/
│       ├── _template/     Copy this to start a secret tool (guard built in)
│       └── <your-tool>/index.html   (your hidden tools appear in the Vault)
├── tools/
│   ├── _template/         Copy this FOLDER to start a new tool
│   ├── pdf/  image/  text/  developer/  converters/  calculators/
│   ├── text/word-counter/   One folder per tool — index.html + assets inside
│   └── image/image-resizer/ (same pattern)
├── sync-tools.ps1         The sync engine (public tools + vault, rewrites auto sections)
└── sync-tools.bat         Double-click me after adding/removing a tool
```

## Design notes

- Fonts: Inter (UI) + JetBrains Mono (kbd accents)
- Light minimal theme: white surfaces, soft borders, indigo→violet gradient accent
- Keyboard shortcut: `/` focuses search · `Esc` clears
- Responsive, respects `prefers-reduced-motion`
